# Code of Conduct

## Our commitment

We are committed to making participation in this project respectful, constructive, and welcoming for everyone, regardless of background, identity, experience level, or technical perspective.

## Expected behavior

- Be respectful and assume good intent.
- Keep feedback specific to the code, design, documentation, or observed behavior.
- Welcome questions and explain unfamiliar concepts without condescension.
- Protect other people's privacy and never request or publish credentials, account identifiers, email addresses, or personal data.
- Respect the project's safety boundaries, including its prohibition on credential sharing, subscription pooling, limit circumvention, and automatic account rotation.

## Unacceptable behavior

- Harassment, intimidation, discrimination, or personal attacks
- Publishing another person's private information without permission
- Deliberately posting credentials, authentication files, tokens, or account identifiers
- Repeated disruption of technical discussion or review
- Misrepresenting this community project as an official OpenAI product

## Scope

This code of conduct applies to repository issues, pull requests, discussions, reviews, and other project spaces. It also applies when someone publicly represents the project or its community.

## Reporting and enforcement

Report conduct concerns privately to the repository maintainer using the contact options on the maintainer's GitHub profile. If a report also contains security-sensitive information, use GitHub private vulnerability reporting.

Maintainers may edit or remove contributions that violate this code of conduct and may temporarily or permanently restrict participation when necessary. Reports will be reviewed in good faith with attention to the safety and privacy of everyone involved.
